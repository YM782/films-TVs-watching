READ THE CHARTS

排名不是同一把尺。

IMDb

Top 250 以常規用戶投票計算加權排名，電影與電視榜分開；電影榜只收錄院線長片。

Rotten Tomatoes

Tomatometer 是影評人正面評價比例；不同編輯榜還可能加入觀眾分數、評論量和編輯調整。

豆瓣

電影 Top 250 會綜合用戶評價與評價人數；劇集榜則依頁面提供的類型、地區等分類瀏覽。

IMDb 榜單透過第三方開源代理讀取 IMDb 公開榜單（代理專案原始碼 ↗），代理服務可能有快取或短暫中斷；請以 IMDb 官方頁面為最終依據。代理只提供排名、片名、年份、評分、投票數及作品連結。海報路徑由 TMDb API 按 IMDb ID 配對；海報 CDN 使用 w500 尺寸，圖片失效時會回退至文字封面。
